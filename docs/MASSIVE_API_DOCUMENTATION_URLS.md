## Free Tier Access: Reference Endpoints Only

With the free MASSIVE API tier, you only have access to **reference endpoints** - those containing `/reference/` in the URL path. These provide metadata, reference data, and foundational information.

### ✅ Available Reference Endpoints (11 unique patterns)

#### Stocks Reference Endpoints (9)
1. **All Tickers**
   - Endpoint: `GET /v3/reference/tickers`
   - Doc: [All Tickers](https://massive.com/docs/rest/stocks/tickers/all-tickers)
   - Description: List all stock tickers with pagination and filtering

2. **Ticker Overview**
   - Endpoint: `GET /v3/reference/tickers/{ticker}`
   - Doc: [Ticker Overview](https://massive.com/docs/rest/stocks/tickers/ticker-overview)
   - Description: Detailed information about a specific ticker

3. **Ticker Types**
   - Endpoint: `GET /v3/reference/tickers/types`
   - Doc: [Ticker Types](https://massive.com/docs/rest/stocks/tickers/ticker-types)
   - Description: List all ticker type classifications (CS, ETF, ADRC, etc.)

4. **Exchanges**
   - Endpoint: `GET /v3/reference/exchanges`
   - Doc: [Exchanges](https://massive.com/docs/rest/stocks/market-operations/exchanges)
   - Description: List all stock exchanges (NYSE, NASDAQ, etc.)
   - Note: Shared across stocks, forex, crypto

5. **Condition Codes**
   - Endpoint: `GET /v3/reference/conditions`
   - Doc: [Condition Codes](https://massive.com/docs/rest/stocks/market-operations/condition-codes)
   - Description: Trade and quote condition code definitions

6. **Stock Splits**
   - Endpoint: `GET /v3/reference/splits`
   - Doc: [Splits](https://massive.com/docs/rest/stocks/corporate-actions/splits)
   - Description: Historical stock split data

7. **Dividends**
   - Endpoint: `GET /v3/reference/dividends`
   - Doc: [Dividends](https://massive.com/docs/rest/stocks/corporate-actions/dividends)
   - Description: Dividend payment history

8. **Financials (Deprecated)**
   - Endpoint: `GET /vX/reference/financials`
   - Doc: [Financials](https://massive.com/docs/rest/stocks/fundamentals/financials)
   - Description: Financial statements (⚠️ Will be removed February 23, 2026)

9. **News**
   - Endpoint: `GET /v2/reference/news`
   - Doc: [News](https://massive.com/docs/rest/stocks/news)
   - Description: Financial news articles and stories

#### Options Reference Endpoints (2)
10. **All Option Contracts**
    - Endpoint: `GET /v3/reference/options/contracts`
    - Doc: [All Contracts](https://massive.com/docs/rest/options/contracts/all-contracts)
    - Description: List all options contracts with filtering

11. **Option Contract Overview**
    - Endpoint: `GET /v3/reference/options/contracts/{options_ticker}`
    - Doc: [Contract Overview](https://massive.com/docs/rest/options/contracts/contract-overview)
    - Description: Details for a specific options contract

#### Shared Reference Endpoints
- **All Tickers** (`GET /v3/reference/tickers`) - Works for stocks, forex, crypto, indices
- **Ticker Overview** (`GET /v3/reference/tickers/{ticker}`) - Works for stocks, forex, crypto, indices
- **Exchanges** (`GET /v3/reference/exchanges`) - Works for stocks, forex, crypto

### ❌ NOT Available on Free Tier (Non-Reference Endpoints)

All endpoints that do **NOT** contain `/reference/` in their path require a paid plan:

- **Aggregate/OHLC Data** (`/v2/aggs/*`) - Historical price bars
- **Snapshots** (`/v2/snapshot/*`, `/v3/snapshot`) - Real-time market snapshots
- **Trades** (`/v3/trades/*`) - Trade data
- **Quotes** (`/v3/quotes/*`) - Quote data
- **Last Trade/Quote** (`/v2/last/*`) - Most recent trade/quote
- **Technical Indicators** (`/v1/indicators/*`) - SMA, EMA, MACD, RSI
- **Market Status** (`/v1/marketstatus/*`) - Market hours and holidays
- **Fundamentals** (`/vX/financials/*`) - Balance sheets, income statements, cash flow
- **Futures** (`/futures/vX/*`) - Futures contracts and data
- **Partner Data** (`/partners/*`) - Benzinga, ETF Global, TMX

### Free Tier Recommendations for Kuberan
